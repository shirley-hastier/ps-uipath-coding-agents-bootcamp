    Days 3–10: Office Hours & Checkpoints¶

    About this section

    Unlike Day 1 and Day 2, these are self-paced days, not scripted ILT sessions — there's no delivery transcript to mine for a coach script. Each day below expands the master deck's one-line focus and checkpoint into a concrete self-paced exercise, grounded wherever possible in real mechanics and gotchas already confirmed from the Day 1/Day 2 transcripts (cross-linked rather than repeated). Where a page goes beyond the deck's one-liner, it's your own use case driving the work, not a fixed script — treat the steps as a starting structure, not a rigid path.

    Daily focus and checkpoints¶

    Day Lesson Focus Checkpoint
    3 Prompting coding agents for UiPath Outcome prompts, constraints, review loops, acceptance criteria Rewrite 3 vague asks into build-ready prompts
    4 UiPath skills and CLI hygiene uip skills, uip tools, auth, output formats, repeatable setup Confirm setup and skills visibility
    5 Low-code agent authoring agent.json, inputs, outputs, prompts, tools, validation Add one input, one output, and validate
    6 MCP server patterns UiPath MCP, external MCP, tool contracts, security review Create a tool catalog
    7 External and coded agents Coded agents, external agents, handoff contracts, Maestro orchestration Define one external-agent contract
    8 Conversational Agents Multi-turn flows, context, fallback, escalation, transcript tests Write 3 transcript-style tests
    9 IXP / DU document intake Extraction, confidence, validation, document-to-action workflow Design extraction and validation flow
    10 Evals, governance, and deployment Eval sets, guardrails, RBAC, publish/deploy/run, promotion checklist Present final readiness review

    Executive tracking¶

    Day Milestone
    2 Use case selected
    4 MVP running
    8 Evaluation completed
    10 Demo ready

    Daily coach rhythm¶

    Three questions to ask at every office-hours check-in:

    1. What changed since yesterday?
    2. What is blocked?
    3. What will you complete next?
