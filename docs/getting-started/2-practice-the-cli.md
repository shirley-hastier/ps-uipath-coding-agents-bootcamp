# 2. Practicing the CLI

Now that the CLI is installed, get comfortable with a few core commands.

```bash
npx uip --help
```

```bash
npx uip auth status
```

```bash
npx uip rpa create-project --location "./exercises"
```

!!! tip "Training Environment"
    All exercises in this bootcamp run against **[{{ training_url }}]({{ training_url }})**,
    tenant **{{ training_tenant }}**.

Take a few minutes to explore the subcommands under `uip` before moving on —
you'll use several of them again in later lessons.
