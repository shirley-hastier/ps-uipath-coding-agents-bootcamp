# 3. Build Your First Agent

Ask your coding agent to scaffold a simple conversational agent:

```bash
npx uip agents create-project --name my-first-agent
```

Then, in your coding agent chat, ask it to:

1. Add a single tool the agent can call
2. Wire up a simple system prompt
3. Run the agent locally and try a few prompts

```bash
npx uip agents run --project my-first-agent
```

=== "If it works"
    Great — move on to the next lesson.

=== "If it doesn't"
    Paste the error into your coding agent and ask it to diagnose and fix
    the issue before continuing.
