# Getting Started with Coding Agents

This section gets you from zero to your first working coding agent.

| Step | What you'll do |
|------|-----------------|
| 1. Installing the CLI and Skills | Install `uip` and the UiPath skills package for your coding agent |
| 2. Practicing the CLI | Run a handful of `uip` commands to get comfortable with the tool |
| 3. Build Your First Agent | Scaffold, run, and debug a simple agent |

By the end, you'll have a working local setup and a first agent you built
yourself.
